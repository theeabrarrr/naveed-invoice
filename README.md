# NK AC Technical Services - Billing & Invoice Web Application

A clean, responsive, single-page billing and quotation web application designed for AC Technical Services.

## Features
- **Mode 1: Service Invoice / Final Bill** (Final billing with itemized charges, discounts, and payment status).
- **Mode 2: Estimate / Quotation** (Pre-work estimates with customizable validity and item costs).
- **Mode 3: Blank Billbook Sheet** (Printable format for manual handwritten invoices on-site).
- **A4 Single-Page Print Optimization**: Custom print CSS guarantees an exact 1-page fit on paper and clean PDF export.
- **Client-Side & Offline Ready**: Fast loading, runs directly in the browser with zero external server dependencies.

## Deployment
This project is ready for one-click deployment on [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
